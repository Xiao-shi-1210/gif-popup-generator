# GIF 弹窗生成器

在线使用：[打开 GIF 弹窗生成器](https://xiao-shi-1210.github.io/gif-popup-generator/)

支持上传图片、实时预览动态弹窗及导出 GIF。

## 部署与维护

- 网站由 GitHub Pages 长期托管，使用仓库内的 HTML、Logo 和字体文件，不依赖本机运行或临时预览服务。
- 向 main 分支提交更新后，.github/workflows/pages.yml 会自动重新部署。
- 部署状态见仓库 Actions 中的 Deploy to GitHub Pages。
- 仓库名为 gif-popup-generator，请保留末尾的 r，并使用上面的网页地址访问工具。

原版本说明保留在 README.txt。
